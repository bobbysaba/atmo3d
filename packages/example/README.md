# atmo3d-example

The worked example of an atmo3d data type: a reader of gridded netCDF with named x, y,
z and time. It is the pattern new data types are copied from, not part of the atmo3d app.
Each file says what is required and what is optional; the contract it follows is
[Writing a data type](../../docs/datatypes.md). Its tests: `tests/test_example.py`.
